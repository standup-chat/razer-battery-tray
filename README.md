# Razer Battery Tray

Razer のワイヤレスマウスのバッテリー残量を、Windows のタスクトレイ（時計の横）に表示する常駐アプリです。
Razer Synapse の API や専用ドライバは使わず、USB HID で直接マウスに問い合わせます。

動作確認済み: **Razer DeathAdder V3 Pro**（HyperSpeed ドングル接続）

## できること

- **マウス型アイコン**の中の水位で残量を表示（60秒ごとに自動更新）
  - 緑: 51%以上 / 黄: 21〜50% / 赤: 20%以下（輪郭も赤） / 灰色の輪郭だけ: 未検出・スリープ中
  - 充電中は稲妻マーク。タスクバーがライトテーマなら輪郭は濃い色に
- **通知**: 残量が 20% と 10% を切ったとき、充電が完了したとき
- **残り時間の予測**: 減り方から「残り使用時間」、充電中は「満充電まで」の時間を表示
  （PC の電源オフやマウスのスリープ中は数えない、使用時間ベース。使い始めは「計測中」）
- **右クリックメニュー**
  - 現在の残量と予測時間
  - 今すぐ更新（アイコンの左クリックでも可）
  - 通知を表示（オン/オフ）
  - Windows 起動時に自動で起動（オン/オフ）
  - ログ・履歴のフォルダを開く
  - 終了
- 二重起動しません（起動中にもう一度起動すると「すでに起動しています」と表示して終了）

## セットアップ

1. Python 3.10 以降を入れる
2. このフォルダでターミナルを開き、ライブラリを入れる
   ```
   pip install -r requirements.txt
   ```
3. 動作確認（ドングルを挿し、マウスの電源を入れて少し動かした状態で）
   ```
   python razer_battery_tray.py --diag
   ```
   「本番と同じ読み取り: (79, False)」のように残量が出ればOK。
4. 常駐させる（コンソール窓なし）
   ```
   pythonw razer_battery_tray.py
   ```
5. トレイのアイコンを右クリック →「Windows 起動時に自動で起動」にチェック

`python` は結果を画面に出す窓あり版、`pythonw` は窓なしで裏で動く版です。確認は `python`、常駐は `pythonw` を使います。

### 自動起動について

メニューのチェックで、レジストリ（`HKCU\...\CurrentVersion\Run`）に起動コマンドを登録します。
pyenv の中継スクリプトではなく本物の `pythonw.exe` のパスを登録し、フォルダを移動しても次の起動時に自動で登録し直します。
pyenv で Python のバージョンを削除した場合は、もう一度チェックを付け直してください。

以前にスタートアップフォルダ（`Win + R` → `shell:startup`）へ手動でショートカットを作っていた場合は、そちらは削除してください。

### アイコンが見えないとき（Windows 11）

トレイの「^」の中に隠れています。アイコンを時計の横（他のアイコンが並んでいるあたり）へドラッグするか、
設定 → 個人用設定 → タスクバー →「その他のシステム トレイ アイコン」で `Python` / `pythonw` をオンにしてください。

## 保存されるデータ

`%APPDATA%\RazerBatteryTray`（メニューの「ログ・履歴のフォルダを開く」で開けます）

| ファイル | 中身 |
|---|---|
| `log.txt` | 起動・接続・通知・エラーの記録（1MB × 3世代で自動ローテーション） |
| `history.csv` | 残量の記録（時刻, 残量%, 充電中）。予測に使用。7日より古い分は自動で削除 |
| `settings.json` | 通知のオン/オフ |

## うまく動かないとき

- `python razer_battery_tray.py --diag` の出力を確認。どのインターフェースも `status=ok` にならなければ、Razer Synapse を一度終了して再実行
- マウスがスリープ中だとドングルは応答しないので、マウスを少し動かしてから「今すぐ更新」
- それでもダメなら `--diag` の出力と `log.txt` を添えて Issue で報告してください
- 更新間隔・色の境目・通知のしきい値は、ファイル先頭の `POLL_SECONDS` / `LOW_THRESHOLD` / `MID_THRESHOLD` / `NOTIFY_LEVELS` で変更できます

## exe にしたい場合（任意）

```
pip install pyinstaller
pyinstaller --onefile --noconsole razer_battery_tray.py
```
`dist\razer_battery_tray.exe` を起動し、メニューから自動起動にチェックすれば Python なしでも動きます。

## 仕組み

Razer 機器は 90 バイトの HID フィーチャーレポートで命令を受け付けます。
コマンドクラス `0x07` / ID `0x80` がバッテリー残量（0〜255）、`0x84` が充電状態です。
ドングルには複数の HID インターフェースがあるため、残量に正しく応答するものを自動で探します。
